## 摘要
我们研究了边界维数至少为三的连通紧流形上 Dirichlet-to-Robin 映射 $\mathcal{D}_g$ 谱的变分性质。对于第一特征值，我们证明了 Type II Yamabe 度量极值化了第一归一化特征值泛函，并刻画了所有极值度量。若 $[g]$ 是一个共形类，且 $\mathcal{D}_g$ 在该共形类中至少有两个负特征值，则我们证明了存在一个广义度量，使得 $\mathcal{D}_g$ 在共形类中的第二归一化特征值达到极大。此外，我们证明了每个这样的度量要么定义了边界上变号的流形上的 Escobar--Yamabe 型方程的解，要么定义了到单位欧几里得球的弱自由边界调和映射。

## Abstract
We study the variational properties of the spectrum of the Dirichlet-to-Robin map $\mathcal{D}_g$ on connected compact manifolds with boundary of dimension at least three. For the first eigenvalue, we show that Type II Yamabe metrics extremize the first normalized eigenvalue functional, and we characterize all extremals. If $[g]$ is a conformal class for which $\mathcal{D}_g$ has at least two negative eigenvalues, then we show the existence of a generalized metric that maximizes the second normalized eigenvalue of $\mathcal{D}_g$ in the conformal class. Moreover, we show that each such metric either defines a solution to an Escobar--Yamabe type equation on manifolds with boundary that changes sign along the boundary, or a weakly free-boundary harmonic map into the unit Euclidean ball.

  - \(Q>0\)：极小化 \(F_1\)，极值度量与正的第一广义特征函数相关，且对应的度量为 Type II Yamabe 极小元。
  - \(Q=0\)：\(F_1\equiv 0\)。

  \[
  F_{2,\epsilon}(u)=\lambda_2(u)\left(\int_\Sigma u^N d\sigma_g\right)^{\frac{N-2}{N}} - \left(\int_\Sigma u^{-\epsilon}d\sigma_g\right)\left(\int_\Sigma u^N d\sigma_g\right)^{\frac{\epsilon}{N}},

  其中 \(\epsilon>0\) 为参数。对每个 \(\epsilon\) 证明极大元的存在性，并通过一系列与 \(\epsilon\) 无关的一致估计（有界性、正则性、欧拉–拉格朗日方程）取极限 \(\epsilon\to0^+\)，得到原泛函的极大元。
- **正则性技术**：
  - 使用 Sobolev 迹嵌入、Friedrichs 不等式、Moser 迭代得到广义特征函数的 \(L^\infty(M)\cap L^\infty(\Sigma)\) 估计。
  - 利用椭圆伪微分算子正则性获得边界 \(C^{0,\alpha}\) 和 \(W^{1,p}\) 一致估计。
  - 结合 Harnack 不等式与唯一延拓原理（Z. Li 的近期结果）证明极值函数零点集的 Hausdorff 维数不超过 \(n-2\)。

  \gamma_{1,\epsilon}u_\epsilon^N-u_\epsilon^{N-2}\sum_{i=1}^k c_{i,\epsilon}\phi_{i,\epsilon}^2-\gamma_{2,\epsilon}u_\epsilon^{-\epsilon}=0
  \]
  的方程，最终在极限中得到
  \[
  \sum_{i=1}^k \phi_i^2 = u^2 \quad \text{on } \Sigma.

## 6. 主要结论与发现

- **第一特征值极值度量与 Type II Yamabe 度量等价**：
  - 若 \(Q(M,\Sigma,[g])<0\)，则 \(\sup_{g_u\in[g]} F_1(u)=Q(M,\Sigma,[g])\)；若 \(Q>0\) 且满足 Escobar 可解性条件，则 \(\inf F_1(u)=Q(M,\Sigma,[g])\)。
  - 极值度量要么边界共形因子为常数（负情形），要么边界共形因子与第一特征函数成比例（正情形）。
- **第二特征值极大元的存在性**：
  - 在 \(\mathcal{D}_g\) 至少有两个负特征值且 \(0\notin\operatorname{Spec}(\mathcal{D}_g)\) 的假设下，存在广义共形因子 \(u\in C^{0,\beta}(\Sigma)\cap C^\infty(\Sigma\setminus u^{-1}(0))\) 极大化第二归一化特征值 \(F_2\)。
  - 零点集 \(u^{-1}(0)\) 的（边界）测度为零，且 Hausdorff 维数不超过 \(n-2\)。
- **极值度量的正则性刻画**：
  - 对极大元存在有限个第二广义特征函数 \(\{\phi_i\}_{i=1}^k\) 满足 \(\sum_i\phi_i^2=u^2\) 于边界。
  - \(k=1\) 时对应变号的 Escobar–Yamabe 型方程解；\(k>1\) 时构造出到单位欧几里得球的自由边界调和映射。
